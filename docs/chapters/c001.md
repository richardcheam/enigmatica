## Puzzle 3 - Medium-Mode Hill Cipher

### Snapshot

Place the third puzzle image at `assets/chapters/c001/puzzle-03.png`.

![Chapter 1 puzzle 3 snapshot](../../assets/chapters/c001/puzzle-03.png)

### Observed Data

- This stage uses a 2-character Hill cipher over a 31-character alphabet.
- Chapter alphabet used in code: `ABCDEFGHIJKLMNOPQRSTUVWXYZ12345`
- Ciphertext used for the playable puzzle: `QBRAEOME`
- Inverse matrix used for the playable puzzle:
  `[12 6]`
  `[12 2]`

### Mechanic

The underlying code implements a real 2x2 Hill cipher. In the playable version, the player is given the inverse matrix directly, so they only need to apply it block by block instead of deriving the matrix themselves.

### Reasoning

- Read the ciphertext as four blocks: `QB RA EO ME`
- Convert `QB` into numbers using the chapter alphabet:
  `Q = 16`, `B = 1`
- Apply the inverse matrix modulo 31:
  `[12 6; 12 2] * [16; 1] = [198; 194] = [12; 8] mod 31`
- Convert `[12, 8]` back into letters:
  `12 -> M`, `8 -> I`, so `QB -> MI`
- Repeating the same step for the remaining blocks gives:
  `RA -> SS`
  `EO -> IO`
  `ME -> N3`
- Join the plaintext blocks: `MISSION3`
- Remove the trailing filler `3`
