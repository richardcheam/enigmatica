# Chapter Notes

This folder is the project notebook for each manga-inspired puzzle chapter.

Each chapter note should capture:

- the source image or a path to it
- the raw observed symbols or text
- the decoding mechanic
- the reasoning trace
- the final answer
- how the chapter maps to reusable code in `src/`
- ideas for turning the chapter into a game level later

## Conventions

- Store images under `assets/chapters/cXXX/`.
- Keep executable logic in `src/chapters/cXXX.py`.
- Keep reusable helpers in `src/ciphers/`.
- Add one markdown note per chapter in `docs/chapters/`.
